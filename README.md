# cryptocurrencies-portfolio

As a Bitcoiner, I'm obsessed with the idea of managing the amount of crypto I HODL. This app uses Ruby on Rails, ReactJS, and the CoinMarketCap API.

## Local setup

The application reads the CoinMarketCap credential from the environment. Do not commit API credentials to the repository.

```bash
export COINMARKETCAP_API_KEY="your-api-key"
```

Any credential that has previously been committed to repository history should be revoked and replaced in the CoinMarketCap account before using the application again.
